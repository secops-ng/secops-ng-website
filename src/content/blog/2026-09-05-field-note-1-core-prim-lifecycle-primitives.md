title: "CORE-PRIM lifecycle primitives for unbound execution steps"
date: 2026-09-05
---

We have added CORE-PRIM lifecycle primitives for unbound execution steps across seven critical capability areas:

- Business continuity: seven step primitives plus the OCSF milestone composers
- Cryptographic controls: six lifecycle primitives
- DDoS response: six response primitives
- Data subject rights: seven lifecycle primitives
- Agentic threat response: five response primitives
- Vulnerability management: pinned per-step D3FEND technique set
- EIDAS2 identity verification: five verification primitives

These primitives enable operators to compile deterministic, step-level orchestrations with complete execution paths.
The changes close several tracking issues and mature the framework's reference compiler tooling.
